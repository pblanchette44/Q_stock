# Q_stock

A lightweight stock search app built in Swift using SwiftUI.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/pblanchette44/Q_stock.git

2. **Open the project**

2. **Navigate into the project folder**

3. **Open the .xcodeproj file with Xcode**

4. **Build and run**

No external dependencies or package managers are required

## 🧱 Project Structure
The code is organized into three main folders:

Views – All SwiftUI views

ViewModels – ObservableObject-based logic and state management

Network – Contains networking code and service abstractions

Each file contains inline comments that explain the architectural intent.

## 🧪 Testing and Caching
Due to time constraints, Unit tests and UI tests are not included in this version

Caching has also been omitted for simplicity

However, documentation in the codebase outlines how these features would be implemented in a future iteration.
